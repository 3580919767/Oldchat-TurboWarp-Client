## FAQ

**Q**：使用说明书什么时候写完
**A**：等我什么时候有心情写了再说吧

**Q**：为什么会话列表和聊天记录能编辑
**A**：因为在打包的时候勾选了"Editable lists"选项，所以列表可以编辑
**Q**：那如果我乱改它们会发生什么
**A**：不会发生什么，因为`会话列表` `聊天记录` `全屏聊天记录`这三个列表只是用来展示给你看的，程序不依赖它们进行判断，即使你改了它们，刷新一下就会全部恢复
